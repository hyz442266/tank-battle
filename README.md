# 坦克大战 · Tank Battle

一个纯 HTML / Canvas 实现的经典坦克大战游戏，单文件、零依赖，双击即可运行，也适合部署到 GitHub Pages。

## ✨ 功能特性

- 🎮 **经典玩法**：驾驶坦克保卫基地，消灭所有敌人坦克
- 🗺️ **多个关卡**：3 个手绘地图循环推进，难度递增
- 🤖 **敌人 AI**：多种敌人类型（普通 / 快速 / 威力 / 装甲），会随机移动、卡墙转向并朝玩家开火
- 💥 **可破坏场景**：砖墙可被击毁，钢墙需要强化弹，水面/树林/冰面各有不同效果
- 🎁 **道具系统**：加命、护盾、强化弹、全屏炸弹、冰冻敌人
- 🔊 **音效**：Web Audio 合成音效（可一键静音，`M`）
- 🏆 **最高分**：本地 localStorage 记录最高纪录
- 📱 **触屏支持**：手机/平板自动显示虚拟方向键

## 🕹️ 操作方式

| 操作 | 按键 |
| ---- | ---- |
| 移动 | `W A S D` 或 方向键 |
| 开火 | `空格` 或 `J` |
| 开始 / 重新开始 | `Enter`（或点击按钮） |
| 暂停 / 继续 | `P` |
| 声音开关 | `M` |

> 手机端自动显示虚拟按键。

## 🚀 运行方式

直接双击 `index.html` 在浏览器中打开即可。

或在项目目录启动一个本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve
```

然后访问 `http://localhost:8000`。
